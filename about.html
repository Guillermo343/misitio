Sobre mí

Soy Guillermo, desarrollador de software. Trabajo con Python, JavaScript, Docker y Linux.

Disfruto convertir ideas en programas que funcionan y que otras personas pueden mantener. Me importa que el código sea legible, que el entorno sea reproducible y que el despliegue no sea un dolor de cabeza.

Fuera del teclado, sigo aprendiendo herramientas nuevas y compartiendo lo que descubro.

Lo que uso

Python

Automatización, scripts, APIs y análisis de datos.

JavaScript

Interfaces web interactivas y lógica del lado del cliente, sin depender de frameworks cuando no hacen falta.

Docker

Contenedores para que cada proyecto funcione igual en mi equipo y en el servidor.

Linux

Administración desde la terminal, servicios, permisos y scripts de shell.
